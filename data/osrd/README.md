# OSRD data used for phase 9 (validation)

| File | Content |
|---|---|
| `osrd_S1_export.csv`, `osrd_S2_export.csv` | OSRD simulation exports (S1 diesel push-pull; S2 EMU thermal proxy), Hamilton GO Centre – Oshawa GO, Union track 7, OSRD 4a1a8bdce |
| `lakeshore_topology.json` | Track sections, switches, operational points, signals and detectors of the `lakeshore_corridor` infrastructure (geometry removed) |
| `s2_11r_path.json` | OSRD path of train S2 11R (blocks, routes, track ranges) — used to confirm the block layout (VAL-05) |
| `s3b_conflicts.json` | OSRD conflicts of scenario S3b with zone requirements — used to find the in-section stop error (CR-014) |

The infrastructure was generated from OpenStreetMap. Contains information from OpenStreetMap,
